# AuditIQ

Angular 19 frontend for financial & procurement risk review (MVP: audit period, document upload, tenders/quotes, analysis report).

**Backend HTTP contract:** [README-API.md](./README-API.md)

## Development server

```bash
ng serve
```

Open `http://localhost:4200/`. The app reloads when you change source files.

## Build

```bash
ng build
```

Artifacts go to `dist/`.

## Tests

```bash
ng test
```
